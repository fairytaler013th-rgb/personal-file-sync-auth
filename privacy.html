数据使用说明

“GitHub / Drive 本地备用同步”仅供所有者本人使用。

程序读取 Drive 变化记录和文件元数据，以识别指定目录的增量；只按配置传输项目文件。Google Docs 正文、普通文本和版本信息用于文件同步、回读校验和冲突保护。Apps Script 源码只读权限用于让本机运行已部署的同一套同步逻辑。

按配置选中的内容会在所有者的 Google Drive 与 GitHub 仓库之间传输。游标、文件映射、版本基线和错误记录存放在所有者的 Apps Script 私有属性、私有 Drive 控制文件和本机；技术异常快照按项目配置保存到对应仓库。未选中的文件正文不会被上传到 GitHub。

Google 凭据由本机官方 clasp 授权存储保存；GitHub 凭据存放在所有者已有的官方 CLI 授权存储或 Apps Script 私有属性。凭据不会写入代码仓库或公开网页。

程序不向 AI 模型发送同步数据，不出售数据，也不使用广告或统计追踪。数据仅用于所有者请求的文件传输和故障恢复。Google API 数据的使用遵循 Google API Services User Data Policy，包括 Limited Use 要求。

所有者可在 Google 账号的第三方连接设置撤销授权，停止本机计划任务并移除本机授权。撤销同步授权不会自动删除项目文件；项目内容和故障记录由所有者按原存储服务的权限管理。

这是单人自用工具；如需说明或修正，请通过与工具所有者已有的联系渠道沟通。
